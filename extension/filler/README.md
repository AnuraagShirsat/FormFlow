# Form Filler (/extension/filler)

**Owner:** Kartik

## Scope & Responsibilities
- DOM scanner to detect and map form fields (inputs, selects, textareas, file inputs).
- Field matching engine mapping extracted profile data to target form fields.
- Form filling execution triggered ONLY upon explicit student action (clicking "Fill Form").
- NEVER auto-submits any form.
- Photo and signature normalizer fixing dimensions, file size, and allowed file types according to form rules.
