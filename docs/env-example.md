# Documentation: `.env.example`

## 1. What it does
`.env.example` provides the canonical environment template for the FormFlow backend. It communicates the required configuration variables to developers and deployment environments without exposing any real secrets.

## 2. How it works technically
Defines 5 core environment variables:
- `GEMINI_API_KEY`: Secret API key for Google Gemini API. Left blank in the template.
- `GEMINI_MODEL`: Specifies the target Gemini model version (default: `gemini-1.5-flash`).
- `ALLOWED_ORIGIN`: Chrome extension origin format (`chrome-extension://<extension-id>`).
- `PORT`: Network port for the Express HTTP server (default: `5000`).
- `RATE_LIMIT_PER_MIN`: Maximum permissible requests per client IP per minute window (default: `30`).

## 3. Judge questions with short answers
- **Q: Why is `.env.example` committed to version control, but `.env` is ignored?**
  - **A:** `.env.example` serves as documentation showing required configuration keys without secrets. The actual `.env` holds sensitive credentials and is strictly excluded via `.gitignore`.
- **Q: What is the format of `ALLOWED_ORIGIN`?**
  - **A:** It takes the form `chrome-extension://<id>`, where `<id>` is the extension identifier generated by Chrome when loading unpacked.

## 4. What to know before the judges
- When demonstrating locally, copy `.env.example` to `backend/.env` and paste your Gemini API key.
- On cloud platforms (Render/Railway), these key-value pairs are configured in the environment settings dashboard.

## 5. Security checks done and judge questions about security
- **Security Checks Done:**
  - Verified `.env.example` contains zero actual keys or live credentials.
  - Confirmed `.gitignore` protects against accidental check-ins of `.env`.
- **Judge Security Questions:**
  - **Q: What happens if someone leaves `ALLOWED_ORIGIN` blank in production?**
    - **A:** If `ALLOWED_ORIGIN` is configured, all requests without matching origin are blocked. In production deployments, setting `ALLOWED_ORIGIN` ensures only the official extension can talk to the proxy.
