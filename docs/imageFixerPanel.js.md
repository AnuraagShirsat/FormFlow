# Documentation: `/extension/ui/imageFixerPanel.js`

## 1. What It Does
`imageFixerPanel.js` provides the user interface for the "Photo" tab in the FormFlow widget. It exposes `window.FormFlow.ui.renderFixerPanel(container, ctx)` and allows students to:
- Select from supported Indian portals (SSP Karnataka, NSP, NTA JEE Main, UPSC, IBPS, SSC, Mock Portal).
- Toggle between Passport Photo and Scanned Signature modes.
- Inspect whether portal specifications are verified or unverified.
- Upload an image file and view side-by-side before/after preview comparisons with exact pixel dimensions and file sizes in KB.
- Download the optimized `.jpg` artifact with a single click.

---

## 2. How It Works Technically
- **Specification Ingestion (`GET_SPECS`):** Requests portal dimensions from the background worker via `sendToBackground('GET_SPECS')`. In offline dummy mode (`ctx.useDummy`), uses built-in default specifications from `BUILTIN_FALLBACK_SPECS`.
- **Unverified Specification Guard:** If `spec.verified === false`, renders an alert notice cautioning the student to verify requirements against their portal's official information bulletin.
- **Side-by-Side Visual Comparison:**
  - Displays original image preview with file size in KB.
  - Passes the file to `window.FormFlow.ui.fixImage(file, spec)`.
  - Displays the optimized preview with exact pixel dimensions, compressed size, and quality metric.
- **Client-Side Direct Download:** Creates a temporary download link with `download="photo_<portal>.jpg"`, triggers a virtual click, and revokes the generated object URL immediately after download.
- **Memory Safety:** Automatically revokes previous preview URLs on file replacement or panel re-rendering via `revokeSafeObjectURL`.
- **Pure DOM Generation:** Built strictly using `window.FormFlow.ui.el` with zero `innerHTML` or dynamic string evaluation.

## 3. Judge Questions with Short Answers

**Q: Why have a Photo and Signature Fixer in a form-filling extension?**  
**A:** Government and scholarship portals in India reject thousands of student applications annually due to mismatched photo aspect ratios or file sizes exceeding arbitrary limits (e.g., 50 KB or 20 KB). Integrating an automated offline fixer solves this hurdle directly in the student's workflow without requiring third-party image editor tools.

**Q: What does the "unverified spec" notice indicate?**  
**A:** If a portal specification in `specs.json` has `verified: false`, the widget alerts the student that the dimensional requirements are synthetic or pending administrator verification, prompting them to cross-reference their official notification brochure.

**Q: Where are the optimized images saved?**  
**A:** Nowhere in the browser extension. When the student clicks "Download", the image blob is transferred to the student's local computer download folder. It is never transmitted across the network or stored in extension storage.

## 5. Security Checks Done and Judge Questions About Security

### Security Checks Done:
- **No Evaluation:** Zero use of `eval()`, `new Function()`, or inline event handlers.
- **Safe Object URL Lifecycles:** All object URLs are tracked and explicitly revoked to prevent heap memory growth.
- **Safe Element Construction:** Image tags, dropdowns, and buttons are constructed purely via safe DOM methods (`document.createElement`).

### Judge Security Questions & Answers:
**Q: Could a malicious URL be injected into image src attributes in the panel?**  
**A:** No. `img.src` is only set to local blob URLs generated by the browser engine (`blob:chrome-extension://...`) via `createSafeObjectURL`. Remote image URLs and dynamic HTML snippets are completely prohibited.

**Q: Does downloading the fixed image trigger file system permission dialogs or extension vulnerabilities?**  
**A:** No. The download uses standard browser HTML anchor download mechanics (`<a download="...".jpg>`), running within standard browser user-download sandboxes.
