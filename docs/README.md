# Documentation (/docs)

**Owner:** Shared / Documentation (Maintained by respective code owners)

## Scope & Responsibilities
- System architecture, workflow diagrams, and component specifications.
- Per-file judge preparation documentation (`/docs/<file-name>.md`) with 5 mandatory sections:
  1. What it does
  2. How it works technically
  3. Judge questions with short answers
  4. What to know before the judges
  5. Security checks done and judge questions about security
- Demo walkthrough guides and hackathon presentation cheat-sheets.
